# Imagen conceptual de una interfaz

Usá esta representación cuando se solicita generación de imagen o cuando hace falta explorar carácter visual, jerarquía y composición. Para texto exacto, controles inspeccionables o estados que deban funcionar, preferí renderizar un prototipo; si el usuario pidió explícitamente una imagen generada, respetá ese medio y señalá sus límites.

Prepará un brief con el trabajo que debe permitir la pantalla, contenido necesario, jerarquía, identidad y cambios concretos. Incorporá referencias visuales disponibles indicando qué aporta cada una: identidad, distribución o interacción. Una referencia de distribución no autoriza copiar su marca. Una regla del diseño puede cuestionarse como propuesta explícita, conservando el resto de la identidad.

Usá una herramienta de generación de imágenes para producir o editar el bitmap solicitado; aplicá sus instrucciones de uso. Inspeccioná las imágenes de referencia antes de utilizarlas. Si la herramienta no está disponible, explicá la limitación y qué medio alternativo permitiría avanzar; no presentes HTML como si fuera una imagen generada ni prometas un resultado que no produjiste.

En cada refinamiento, indicá exactamente qué cambia y qué debe mantenerse. Comprobá en la imagen obtenida que se conservaron los elementos aceptados. Las correcciones de texto o detalles no pueden asumirse resueltas por haberlas incluido en el prompt.

Identificá el resultado como concepto, con datos de ejemplo cuando corresponda. Revisá textos, cifras, etiquetas, acciones y posibles elementos inventados. Señalá cualquier diferencia material que permanezca. Una imagen de interfaz no demuestra flujo, responsive, accesibilidad ni disponibilidad de datos o capacidades.

Mostrá la imagen inline, conservá una versión identificable y explicá brevemente la dirección. Si después se solicita HTML, trasladá las decisiones al prototipo y comprobá su viabilidad: la imagen no sustituye la especificación del comportamiento. Documentá las diferencias justificadas entre ambos medios.
