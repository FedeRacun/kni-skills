# kni-skills

Skills personales organizadas por función. Cada categoría explica qué skills incluye, para qué sirven y en qué orden usarlas.

## Categorías

| Categoría | Propósito |
| --- | --- |
| [Refactor de UI](skills/refactor-ui/README.md) | Diagnosticar interfaces, proponer y refinar cambios visuales, preparar su implementación y revisar el resultado. |

## Cómo usarlas

Copiá o instalá la **carpeta completa de la skill** en el directorio de skills que utilice tu entorno, manteniendo `SKILL.md` y sus referencias. La forma de descubrir o invocar skills depende del entorno; también podés indicar explícitamente el nombre y la ubicación de su `SKILL.md`.

Consultá el README de la categoría para encontrar el flujo recomendado y ejemplos de pedidos. Las instrucciones de ejecución están en cada `SKILL.md`.

## Organización

Las skills se guardan en `skills/<función>/<nombre>/`. Cada carpeta es autónoma y conserva sus referencias locales. Las futuras skills de planes, ajustes o performance tendrán su propia categoría cuando se incorporen.
